# Welcome to Morion

Morion is your local notebook that doubles as memory for any LLM.

## Quick start

- **Write notes** just like you would in Apple Notes. Bold, headings, checklists, code blocks all work.
- **Organize** with folders (drag notes between them) and tags (color-coded).
- **Search** with Cmd+K. Hybrid search combines keyword matching with semantic understanding.
- **Connect your LLM.** Claude, Cursor, Cline, or any MCP-capable client can read and write these same notes. See Settings for connection snippets.

## Keyboard shortcuts

| Shortcut | Action |
|----------|--------|
| Cmd+N | New note |
| Cmd+K | Search |
| Cmd+D | Delete note |
| Cmd+1/2/3 | Focus sidebar / notes list / editor |
| Cmd+Shift+F | Toggle editor fullscreen |

## Your data is local

Everything lives in a single SQLite file on your machine. No cloud, no account, no sync. Export to markdown anytime.
